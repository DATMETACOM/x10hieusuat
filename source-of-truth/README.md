# Source of Truth

This folder contains the canonical assets and content for the X10 landing page.

## Structure

- `content/`
  - Source text files used to derive the landing page copy.
- `images/`
  - Canonical moderator and speaker images.

## Current canonical files

- `content/landing-page-content-ref.txt`
- `content/source-content.txt`
- `content/moderator-notes.txt`
- `images/moderator.png`
- `images/speaker-primary.png`

## Usage

Use these files as the single source of truth before updating `index.html` or publishing to Vercel.
